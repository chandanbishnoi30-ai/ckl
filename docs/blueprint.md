# **App Name**: CricketTrack

## Core Features:

- Player Profile Management: Admins can add, edit, and view comprehensive player profiles, including personal details, roles (batsman, bowler), and historical data.
- Statistical Data Entry: Coaches/admins can easily input batting, bowling, and fielding statistics for training sessions and matches.
- Performance Dashboard: Players and coaches can view a personalized dashboard displaying key performance metrics and historical statistics in a clear, interactive format.
- Academy Roster Management: Administrators can manage the academy's player roster, assign roles, and categorize players for effective organization.
- User Authentication & Authorization: Secure login for different user types (e.g., Coaches/Admins, Players) with appropriate access levels for data input and viewing.
- Match & Training Session Scheduler: Create, schedule, and record past cricket matches and training sessions, allowing statistical data to be linked to specific events.
- AI-powered Player Performance Insights: A generative AI tool analyzes individual player statistics and provides personalized feedback, identifies areas for improvement, and suggests targeted training recommendations.

## Style Guidelines:

- Primary color: A vibrant and energetic blue (#149FDB) symbolizing focus and clarity, balanced with the dynamic nature of sports. Chosen as `hsl(195, 80%, 45%)`.
- Background color: A very light, airy blue-grey (#E7F5FA) providing a clean, spacious backdrop for data display and enhancing readability. Chosen as `hsl(195, 20%, 95%)`.
- Accent color: A contrasting yet analogous royal blue (#6C89FC) to draw attention to interactive elements and highlight key information. Chosen as `hsl(225, 70%, 65%)`.
- Body and headline font: 'Inter', a modern sans-serif typeface, selected for its excellent readability and neutral, professional aesthetic suitable for data presentation and administrative tasks.
- Utilize a suite of clean, line-based icons that visually represent cricket actions, statistics, and administrative functions, maintaining a modern and user-friendly appearance.
- Adopt a grid-based, responsive layout with ample whitespace, ensuring statistics and player information are presented clearly and are easily digestible on all devices. Prioritize dashboard-like views for performance data.
- Incorporate subtle and swift micro-interactions and transitions, such as slight fades on navigation clicks or quick highlight effects on data points, to provide clear feedback without distracting from critical information.
